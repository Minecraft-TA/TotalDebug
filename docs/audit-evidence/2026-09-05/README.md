# Audit evidence, 2026-09-05

These are audit probes and captured results, not production regression tests. They intentionally demonstrate defects in the recorded baseline. Promote them into the relevant test suites while fixing the findings in [the release audit](../../RELEASE_AUDIT.md).

The first fix batch is recorded in [release stabilization progress](../../RELEASE_PROGRESS.md). `script-lifecycle-regression-red.txt` and `transport-lifecycle-regression-red.txt` capture six script and four transport cases failing before their fixes. Those cases now live in `ScriptRunnerTest` and SCNet's `ReconnectLifecycleTest` and pass. `ScriptLifecycleFixProbe.java` adapts the original production service probe to require Stop completion, terminal delivery and no JVM deadlock; its passing output is `script-lifecycle-fix-output.txt`. Run it with the current TotalDebug test runtime classpath using the same compilation method as the original probe. `deadlock-fix-artifact-hashes.json` identifies the locally verified outputs and records the packaged transport comparison. The original failure evidence below remains unchanged.

- `TransportAuditProbe.java` and `transport-probe-output.txt`: two deterministic SCNet failures, callback mutation during dispatch and reconnect/callback close deadlock. Run with Java 21 from SCNet using `java --class-path build/classes/java/main <path-to-probe.java>` after its wrapper build. The deliberately blocked fixture threads are daemon threads; process exit closes their sockets.
- `ServerPublicationProbe.java` and `server-publication-probe-output.txt`: 5,000 early-closure attempts did not reproduce the source-level server publication window. This is negative evidence, not a passing deterministic ordering test.
- `ScriptLifecycleAuditProbe.java` and `script-lifecycle-probe-output.txt`: TotalDebug service/run monitor inversion. Compile the probe with the audited TotalDebug test runtime classpath, then run `com.github.minecraft_ta.totaldebug.client.script.ScriptLifecycleAuditProbe` with that classpath plus the compiled probe directory. Reflection is used to wire the existing package-private test factory and to pause result delivery at the real lock boundary. The probe does not connect to Minecraft.
- `CompanionEvaluationAudit.java` and `companion-evaluation-audit-output.txt`: real child-JVM JDWP evaluations against the isolated Companion assembly. Compile with Companion's main/test output plus its shaded JAR; run the class declared in the fixture with those entries plus the compiled probe directory. This output includes overload, numeric/string semantics, lexical binding and target pin retention cases.
- `public-dependencies-output.txt`: a wrapper-driven resolution probe containing only Maven Central and the configured public Packagecloud repository. Maven Local was absent. All four required coordinated dependencies were unresolved.
- `artifact-hashes.json`: SHA-256 values of audit artifacts, not approved release candidates. The Companion artifact was produced before its icon test failed. TotalDebug and Companion exclude the in-progress performance runtime changes as described in the report.

The isolated assemblies remain at `C:\Users\Admin\IdeaProjects\TotalDebug\.codex\release-audit-workspace`. Original full build logs are `C:\Users\Admin\IdeaProjects\TotalDebug\.codex\audit-*-build.log`. The exact TotalDebug probe classpath was written to the isolated build's `audit-classpath.txt`. Probe output may include harmless local test JVM ports and JDI object IDs; these are not credentials or live Minecraft endpoints.

The initial SCNet command used an unquoted PowerShell property argument, which Gradle parsed as a task name. It was corrected to `'-PscnetVersion=2.0.0'` before the successful build. This invocation error was not counted as a repository defect.
